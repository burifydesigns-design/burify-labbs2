# Burify Labs Logo Concept

## Brand Mark Overview

The Burify Labs logo mark should be a **simple, geometric symbol** that communicates intelligence, transformation, and systems — without relying on clichés like AI brains, circuit boards, or robots.

---

## Design Requirements

### Must Be
- Simple enough for 16×16px favicon
- Geometric and clean
- Versatile across backgrounds
- Modern and timeless
- Distinctive at small sizes

### Must Not Be
- Literal AI imagery
- Complex or detailed
- Trendy or dated
- Similar to competitor logos
- Relying on color for recognition

---

## Conceptual Directions

### Option 1: Abstract B — "Burify"

A stylized letter "B" formed by geometric shapes, representing the brand name while remaining abstract.

**Concept:**
- Two or three geometric shapes forming a B-like form
- Negative space creates the B shape
- Can suggest transformation (layers, steps)

**Visual Treatment:**
```
┌───┐
│   │──┐
│   │  │
│   │──┘
└───┘

Or:

┌─┬─┐
│ │ │
├─┤ │
│ │ │
├─┤ │
│ └─┘
└───┘
```

**Variations:**
- Solid fill version
- Outline version
- With/without inner detail

Minimal dots or circles connected by lines, representing systems, networks, and automation.

- Connected by thin lines
- Suggests intelligence and connectivity

**Symbolism:**
- Dots = nodes, ideas, components

### Option 3: Flow / Transformation

Abstract shapes suggesting movement and transformation from one state to another.

**Concept:**
- Simple geometric shapes (circles, squares, triangles)
- Arranged to suggest flow or transformation
- Dynamic but not aggressive

**Visual Treatment:**
```

○ → ◐ → ◉
```

**Symbolism:**
- Circles/forms = ideas or elements
- Arrow/movement = process or automation
- Evolution = transformation

## Recommended Approach

### Primary Recommendation: Option 1 or 3

**Option 1 (Abstract B)** provides the strongest brand recognition while remaining simple and versatile. The geometric approach aligns with modern tech aesthetics.

**Option 3 (Flow/Transformation)** aligns well with the "Burify" concept — transforming and improving systems.

### Implementation Notes

1. **Simplicity First**
   - Start with the simplest version
   - Add detail only if it enhances recognition
   - Test at 16×16px, 32×32px, and full size

2. **Color Usage**
   - Primary: Use primary purple for main elements
   - Accent: Can use pink for highlight elements
   - Monochrome version should work on all backgrounds

3. **Geometry**
   - Use consistent stroke widths (2px recommended)
   - Round corners slightly (2px radius)
   - Maintain visual balance

4. **Proportions**
   - Maintain aspect ratio in all sizes
   - Ensure sufficient negative space
   - Test with surrounding elements

## File Formats

### Vector (Preferred)
- SVG (primary)
- EPS (print)
- AI (editable)

### Raster
- PNG (transparency)
- ICO (favicon)
- WebP (web optimized)

### Minimum Specifications
- SVG: Clean paths, no embedded images
- PNG: 1x, 2x, 3x for retina
- ICO: 16, 32, 48, 256px sizes

---

## Usage Guidelines

### Clear Space
- Maintain minimum 8px (or 0.5x icon height) clear space around icon
- Keep wordmark from crowding other elements

### Minimum Size
- Never use icon below 24px width
- Never use wordmark below 80px width

### Color Application
- Light backgrounds: Full color or monochrome dark
- Dark backgrounds: Full color or white
- Single color print: Monochrome version

### Don'ts
- Don't stretch or distort
- Don't change colors outside brand palette
- Don't add effects (shadows, gradients) to logo
- Don't use on busy backgrounds without clear space
