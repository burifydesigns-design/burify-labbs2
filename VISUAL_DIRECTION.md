# Burify Labs Visual Direction

## Design Philosophy

The Burify Labs visual identity should feel like a **premium technology studio** — clean, sophisticated, and intelligent. Think Linear, Vercel, or Stripe, but with a distinctive purple-pink accent palette.

### Core Principles

1. **Typography First** — Strong typographic hierarchy is the foundation
2. **Generous Whitespace** — Let content breathe
3. **Restrained Color** — Purple and pink as accents, not overwhelming
4. **Geometric Precision** — Clean lines, consistent spacing
5. **Subtle Motion** — Animation that enhances, not distracts

## Homepage Visual Direction

### Hero Section
- **Layout:** Full-width, large typography, minimal elements
- **Typography:** Display size headline (72px desktop), clear value proposition
- **Background:** Subtle gradient or solid with accent elements
- **CTA:** Prominent primary button, secondary text link
- **Visual Elements:** Optional abstract geometric shapes, subtle grid pattern

### Services Overview
- **Layout:** 3-column grid on desktop, cards with icons
- **Cards:** Light background, subtle border, hover lift effect
- **Spacing:** Generous padding between elements
- **Icons:** Geometric, consistent stroke weight

### Featured Work
- **Layout:** Large project images, minimal text
- **Images:** 4:3 aspect ratio, subtle shadow
- **Hover:** Image scale, reveal additional info
- **Typography:** Project name prominent, tech tags subtle

### Social Proof
- **Layout:** Testimonial cards or stats row
- **Stats:** Large numbers with labels
- **Testimonials:** Quote, author, company
- **Trust Signals:** Client logos if appropriate

### CTA Section
- **Layout:** Full-width dark section or gradient
- **Typography:** Bold headline, supporting text
- **Button:** Primary CTA prominent

## Typography Application

### Headlines
- **Weight:** 600-700
- **Color:** Primary text color
- **Spacing:** Tight letter-spacing (-0.02em)
- **Alignment:** Left or center based on section

### Body Copy
- **Weight:** 400
- **Color:** Secondary text color
- **Size:** 16-18px for readability
- **Line Height:** 1.5-1.75

### Labels/Tags
- **Weight:** 500
- **Size:** 12px
- **Transform:** Uppercase
- **Spacing:** Wide letter-spacing

### Buttons
- **Weight:** 500
- **Size:** 14px
- **Transform:** None (sentence case)

---

## Image Treatment

### Style Guidelines
- **Aspect Ratios:** 4:3 (projects), 16:9 (hero), 1:1 (team)
- **Border Radius:** 12-16px for cards, 8px for smaller elements
- **Shadows:** Subtle, consistent with card shadows

### Mockups
- **Style:** Clean, minimal device frames
- **Background:** Neutral or transparent
- **Shadow:** Subtle drop shadow

### Photography
- **Style:** Professional, not overly edited
- **Tone:** Natural lighting preferred
- **Subjects:** Real team, real work

---

## Animation Guidelines

### Scroll Reveals
- **Elements:** Cards, images, text blocks
- **Timing:** 400ms ease-out
- **Stagger:** 100ms between items
- **Direction:** Fade up from bottom

### Hover States
- **Cards:** Lift (translateY -2px), shadow increase
- **Buttons:** Scale 1.02, color change
- **Links:** Color transition to accent
- **Images:** Subtle scale 1.05

### Micro-interactions
- **Buttons:** Press effect (scale 0.98)
- **Forms:** Focus ring animation
- **Navigation:** Smooth transitions between states

### Page Transitions
- **Type:** Fade or slide
- **Duration:** 300-400ms
- **Easing:** Ease-in-out

## Responsive Behavior

### Mobile (< 640px)
- Single column layouts
- Stacked navigation
- Touch-friendly targets (44px min)
- Reduced spacing
- Smaller typography scale

### Tablet (640px - 1024px)
- 2-column grids
- Condensed navigation
- Moderate spacing
- Adjusted typography

### Desktop (> 1024px)
- Full 12-column grid
- Horizontal navigation
- Generous spacing
- Full typography scale

### Large Desktop (> 1280px)
- Maximum container width (1280px)
- Maximum spacing values
- Full typography display sizes

## Dark Mode Application

### When to Use
- Hero sections on dark backgrounds
- Feature sections for contrast
- CTA sections
- Footer

### Implementation
- Use `.dark` class or system preference
- Maintain contrast ratios
- Adjust shadows for depth
- Keep accent colors consistent

### Components
- Cards: Dark background variant
- Buttons: Light outline variant
- Forms: Adjusted input colors
- Navigation: Light text variant

---

## Accessibility Standards

### Color Contrast
- Text: Minimum 4.5:1 ratio
- Large text: Minimum 3:1 ratio
- Interactive elements: Minimum 3:1 ratio

### Focus States
- Visible focus ring (2px)
- High contrast outline
- Clear focus indicator

### Motion
- Respect prefers-reduced-motion
- Disable animations when requested
- Provide alternatives for essential motion

### Screen Readers
- Semantic HTML
- ARIA labels for icons
- Form labels properly associated
- Alt text for images

---

## Page-Specific CSS Guidelines

### Organization
Each page should have:
- Page-specific component folder (optional)
- Page-level CSS module or inline styles
- Clear separation from global styles

### Naming
- Use semantic class names
- Avoid over-specific selectors
- Prefer composition over inheritance

### Optimization
- Critical CSS inline
- Defer non-critical CSS
- Minimize unused styles
